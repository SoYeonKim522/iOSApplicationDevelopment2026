# IELTS Buddy

> **AI-powered personal tutor for IELTS Speaking practice.**
> An iOS application designed to help students and professionals practice speaking casually, receive objective feedback, and track their improvement over time.

## Problem
IELTS is taken by millions of people every year for university admissions, work visas, and permanent residency applications. However, many learners practise speaking alone and repeatedly make the same mistakes without realising it.
<br>This project was built to address that gap.


## Key Features
- **Bite-Sized Speaking Practice:**
  <br>Quick sessions based on selected IELTS Speaking Part and topic.
  
- **Real-time Transcription:**
  <br>Speech-to-text functionality seamlessly integrated with audio recording.
  
- **AI-Powered Feedback Engine:**
  <br>Powered by GPT AI, the app analyzes your recording to provide an estimated band score, detailed performance feedback, and a smart list of suggested corrections.

- **Review Log (Core Feature⭐️):**
  <br>Saved AI-generated corrections are stored for long-term review.
  Each entry is automatically categorised into Grammar, Vocabulary, or Pronunciation, helping users identify recurring mistakes and track progress over time.


## Tech
- SwiftUI, MVVM
- AVFoundation · Speech framework (audio recording and transcription)
- OpenAI API (question generation + AI feedback via audio-capable model)

## Getting started
1. Clone the repository to your local machine.
2. Open `IELTSBuddy.xcodeproj` in Xcode 15 or later.
3. Configure your Developer Team under the **Signing & Capabilities** tab.
4. Add the provided Secrets.plist file to the project root before running the app.
3. ⌘R to build and run the app
